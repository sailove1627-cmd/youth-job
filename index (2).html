👷 청소년 노동 인권 도우미

청소년 알바 지킴이 💼

달력에서 실제 일하는 날짜를 선택하고, 근무시간과 제안받은 월급을 입력하면 최저임금·주휴수당·야간근로수당 기준으로 내가 적정하게 받는지 확인할 수 있어요.

1. 기본 정보 입력 📝

※ 5인 이상 여부에 따라 야간·연장근로 가산수당 적용이 달라질 수 있어요.

※ 숫자만 입력하세요. 예: 700000

생년월일을 입력하면 만 나이가 자동으로 계산됩니다.

2. 실제 일하는 날짜 선택 📅

방법 1: 자주 일하는 요일을 누르면 이번 달 해당 요일이 한 번에 선택됩니다.
방법 2: 달력에서 일하는 날짜만 직접 클릭해도 됩니다. 다시 클릭하면 선택 해제됩니다.

일
월
화
수
목
금
토
선택한 근무일: 0일

3. 근무 시간 입력 ⏰

예: 09:00 ~ 18:00, 휴게 1시간
실제 근무시간은 8시간으로 계산됩니다.
날짜와 시간을 선택하면 이번 달 예상 근무시간이 표시됩니다.

4. 급여 계산 전 필수 확인 ✅

만 15세 미만인가요? 그렇다면 고용노동부에서 발급받은 취직인허증이 있나요?
부모님, 친권자 동의서와 가족관계증명서를 제출하셨나요?
만 18세 이상으로 계산됩니다.
최저임금, 근로계약서, 휴게시간, 주휴수당은 반드시 확인해야 합니다.
생년월일을 입력하면 필요한 체크리스트가 자동으로 나타납니다.

5. 예상 월급 결과 📊

    꼭 기억하세요! 🚨

    • 근로시간 제한: 만 18세 미만 청소년은 하루 7시간, 일주일 35시간까지만 일할 수 있어요. 합의 시 하루 1시간, 1주 5시간 연장 가능해요.
    • 야간근로 금지: 만 18세 미만 청소년은 밤 10시부터 아침 6시 사이에는 원칙적으로 일할 수 없어요.
    • 야간수당: 상시근로자 5인 이상 사업장에서 22:00~06:00에 일하면 야간근로 가산수당을 확인해야 해요.
    • 금지 업종 안내: 청소년은 PC방, 술을 주로 파는 식당, 유흥주점 등 청소년 고용금지 업소에서는 일할 수 없어요.
    • 근로계약서: 일하기 전 반드시 근로계약서를 작성하고 한 부를 직접 챙기세요.
